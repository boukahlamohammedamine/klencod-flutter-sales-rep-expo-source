# مندوب المبيعات — Expo

تطبيق React Native / Expo عربي باتجاه RTL، مع واجهة ميدانية فحمية وزيتونية وأيقونات متجهية موحدة. يعمل محليًا دون اتصال؛ تعتمد البيانات على AsyncStorage في الجهاز، بينما تبقى فواتير JSON الاحتياطية متوافقة مع مجموعات البيانات في الملف الأصلي.

## الوظائف

إدارة المنتجات والمخزون والتعبئة، فواتير بأسعار المصنع/الجملة/التجزئة، خصومات وربح ومدفوعات، العملاء والديون والتسديدات، المصاريف، ملخصات وتقارير حسب التاريخ، الإعدادات، واستيراد/تصدير JSON. زرا الطباعة في تفاصيل الفاتورة والتقارير يفتحان خدمة الطباعة الأصلية على Android. حذف الفاتورة يعيد كمياتها إلى المخزون، ويمنع حذف عميل مرتبط بفواتير أو تسديدات حفاظًا على سلامة السجل.

## التطوير والتحقق

```bash
pnpm install --prefer-offline
pnpm check
pnpm test
pnpm dev
```

يفتح Preview الويب على المنفذ 8081؛ ويستطيع تطبيق Expo Go مسح QR من لوحة المشروع بعد ربط حساب Expo بها. لا يحتوي التطبيق على تسجيل دخول إلزامي ولا يحتاج بيانات مبيعات إلى خدمة سحابية.

## APK

ملف `eas.json` يهيئ ملف APK داخليًا ضمن ملف البناء `preview` (`android.buildType: apk`). بعد حفظ نسخة المصدر المقبولة، استخدم إجراء **Build Android APK** في لوحة مشروع Manus، واترك APK يكتمل ثم نزّله من بطاقة البناء. لم يُنشأ APK من هذا المستودع بمجرد إعداد المصدر؛ رابط التنزيل لا يظهر إلا بعد نجاح البناء. لا تضع رموز Expo أو بيانات اعتماد البناء في الدردشة أو ملفات المصدر.

## البيانات

من الإعدادات أنشئ نسخة احتياطية بصيغة JSON واحفظها في مساحة ملفاتك من نافذة المشاركة. للاستيراد اختر ملف JSON، راجع عدد السجلات ثم اختر الدمج أو الاستبدال. يطلب التطبيق تأكيدًا إضافيًا عند الاستبدال أو مسح جميع البيانات.
